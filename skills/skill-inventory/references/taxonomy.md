# Taxonomy

- `local`: discovered `SKILL.md` under a designated root.
- `plugin`: advertised `skills://plugins/...` in a registry listing.
- `bundled-not-registered`: included inside another package but not established to be registered.
- `original-project-skill`: authored by this repository and available for local installation.

These types answer different questions: where the file is, whether the platform advertises it, and whether it is licensed to publish. They should never be combined into a misleading installed count.
