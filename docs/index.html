AUDIT PROTOCOL / 06

Method & Provenance.

由证据等级驱动的数据收集、验证、归档和公开发布流程。

01 / SCOPE

限定观察边界

当前容器、可用注册表和接口。宿主机、远程设备、账户 OAuth 权限不在默认观测范围。

02 / ENUMERATE

逐项枚举

系统包、多个 Python 环境、命令、Skills、工具 URI；以原始清单复算统计。

03 / VALIDATE

验证与烟测

运行有限且安全的命令，分别标记观测、通过、失败和未知，禁止“安装即成功”。

04 / PUBLISH

脱敏后公开

只发布原创代码、允许公开的元数据、统计和静态报表；任何凭据始终留在私有环境。
