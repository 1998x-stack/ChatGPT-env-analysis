# 公共 GitHub 仓库发布规则

**允许**：安装的软件名/版本、经脱敏的资源配额、测试结果、公开能力元数据、原创审计脚本和文档。

**禁止或待核准**：环境变量值、token、SSH/私钥、敏感 `.env`、浏览器配置、联系邮箱正文、金融/健康信息、私有 GitHub 仓库内容、秘密目录名、未经授权重分发的第一方/第三方 Skills 源码。

## 发布检查

1. 逐个检查即将提交的文件，而不只检查 README。
2. 确保任何 CSV/JSON 没有额外的 `host`, `password`, `secret`, `token`, `cookie`, `user_data` 值。
3. 检查源码中的模拟示例不要出现可用的生产密钥。
4. 明确不同来源的许可：MIT 仅适用于本项目原创代码。
5. 仓库和 Pages 都是公开渠道；变更后仍需要作审查与留痕。
6. 不在自动化任务中将完整 `$HOME`、`/opt`、`/etc`、`/proc` 目录打包并公开。

回滚指引：立即从公开分支删除敏感文件、吊销实际受影响密钥、按 GitHub 文档清理历史（仅删除最新提交不一定消除历史）。
